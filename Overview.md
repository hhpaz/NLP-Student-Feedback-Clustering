# Discovering Educational Problems from Student Feedback using NLP Clustering

## Overview

This project applies Natural Language Processing (NLP) and Unsupervised Machine Learning techniques to discover hidden patterns in university student complaints.

The goal is to identify major educational problem areas from unstructured student feedback without predefined labels.

## Dataset

Dataset:
University Students Complaints and Reports

Number of feedback reports:
1005 student reports

## Methodology

The workflow includes:

1. Text preprocessing
2. TF-IDF feature extraction
3. K-Means clustering
4. Elbow Method and Silhouette Score analysis
5. PCA visualization
6. Cluster topic extraction
7. WordCloud visualization

## Technologies

- Python
- Pandas
- Scikit-learn
- NLP
- TF-IDF
- K-Means
- PCA
- Matplotlib
- WordCloud


## Results

The model discovered five major clusters representing different categories of student problems, including:

- Academic support and opportunities
- Campus services and facilities
- Student challenges and support needs
- Course accessibility issues
- Learning resources and academic access


## Future Work

Future improvements:
